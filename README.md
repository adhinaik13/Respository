## Engineering principles

**Correctness before cleverness.** Test boundaries, error paths, and state transitions.

**Evidence before claims.** Separate local checks, CI results, benchmarks, and production validation.

**Clarity over noise.** Prefer small interfaces, readable code, and documentation another engineer can act on.

**Limitations in the open.** Say what a project does not implement yet.
